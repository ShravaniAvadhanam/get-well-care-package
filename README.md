# Get Well Soon Care Package 💕

An interactive, mobile-first digital get well soon card.

## Features

- Tap-to-open care package animation
- Soup, flowers, honeybee, cats, F1 racing, and gaming themes
- Pink whimsical design with confetti celebration
- Optimized for mobile

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the repo at [vercel.com/new](https://vercel.com/new)
3. Deploy — no build step needed (static site)

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`
